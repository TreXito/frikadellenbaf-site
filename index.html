A PROJECT BY PHILIPP PODOBRI / TREXITO

A bot for
the long game.

Frikadellen BAF is a headless Rust client for Hypixel SkyBlock. It acts on Coflnet flip data, handles Auction House listings and Bazaar orders, and makes the state of a running bot visible through a web panel and Discord.

01 / THE SYSTEM

More than
the click.

The interesting part of automation is what keeps it useful when a session lasts longer than a demo. These are the main pieces described in the public project documentation.

01

Find & act

Coflnet opportunities feed the Auction House workflow. The client buys underpriced BINs and can relist acquired items.

AH / RUST
02

Mind the orders

The Bazaar side places buy and sell orders, checks fills, collects items and manages stale orders.

BAZAAR
03

Make state visible

A browser panel shows bot state and controls. Discord integration gives linked users remote commands and notifications.

WEB / DISCORD
04

03 / GET THE PROJECT

Read it.
Run it.

The source and current platform builds live on GitHub. You need Minecraft Java Edition and a Coflnet account for flip data. The full setup guide covers authentication, configuration and keeping a session running.

04 / NOTES & LIMITS

A little honesty
belongs here.

Automation can violate Hypixel’s rules and can lead to account penalties. Market conditions, latency and configuration affect results. Figures shown by a bot may be theoretical until items actually sell.

Frikadellen BAF is open source under AGPLv3 and is not affiliated with Hypixel, Mojang or Coflnet. The source and documentation are the best place to check what it currently does.
